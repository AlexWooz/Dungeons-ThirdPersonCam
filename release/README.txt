Third-Person Camera for Minecraft Dungeons (v1.17.0.0, Steam)
==============================================================

Replaces the isometric camera with an over-the-shoulder camera you orbit with the right stick.

REQUIREMENTS
- Dungeons Blueprint Loader 1.0 (Blueprint-Loader.pak) in the same ~mods folder.

INSTALL
1. Copy ThirdPersonCam.pak into:
   <Steam>\steamapps\common\MinecraftDungeons\Dungeons\Content\Paks\~mods\
2. Start the game.

CONTROLS
- F6            Toggle the third-person camera on/off (remembered between levels and restarts)
- Right stick   Orbit the camera (stick-dodging is disabled while the camera is on;
                the dodge button still works)
- R3            Recenter the camera behind the hero
- F7            Open/close the settings panel
    Up/Down     Select a setting
    Left/Right  Change it (Distance, FOV, Sensitivity, Invert Y) - saved automatically

The left stick moves the hero relative to the camera.

UNINSTALL
Delete ThirdPersonCam.pak from ~mods. Settings are kept in
%LOCALAPPDATA%\Dungeons\Saved\SaveGames\ThirdPersonCam.sav and can be deleted too.
